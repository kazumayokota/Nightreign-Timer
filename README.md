# Nightreign Timer

Elden Ring Nightreignの試合時間を管理するための常に最前面に表示されるオーバーレイタイマーアプリです。VOICEVOX統合により、重要なタイミングで音声通知を受け取ることができます。

![Version](https://img.shields.io/badge/version-1.0.1-blue.svg)
![Platform](https://img.shields.io/badge/platform-Windows-lightgrey.svg)
![License](https://img.shields.io/badge/license-Custom-orange.svg)

## 主な機能

- ⏱️ **14分間のゲームタイマー** - 午前フェーズ、収縮、午後フェーズを自動管理
- 🔊 **VOICEVOX音声通知** - 重要なタイミング（4:20, 4:30, 7:30, 11:00など）で自動音声案内
- 🎨 **完全カスタマイズ可能** - 背景画像、フォント、色、オーバーレイの透明度を調整
- ⌨️ **グローバルショートカット** - ゲーム中でもキーボードで操作可能
- 🪟 **常に最前面表示** - ゲームウィンドウの上に常に表示（クリック透過モード対応）
- 💾 **設定の自動保存** - カスタマイズした設定は自動的に保存・復元

## 📥 インストール方法

### 必須環境

- Windows 10/11
- [VOICEVOX](https://voicevox.hiroshiba.jp/)（音声通知機能を使用する場合）

### インストール手順

#### 方法1: インストーラー版（推奨）

1. **最新版をダウンロード**
   - [Releases](https://github.com/kazumayokota/Nightreign-Timer/releases)ページを開く
   - 最新バージョンの `Nightreign Timer Setup 1.0.1.exe` をダウンロード

2. **インストーラーを実行**
   - ダウンロードしたファイルをダブルクリック
   - Windows Defender SmartScreenの警告が表示された場合：
     1. 「詳細情報」をクリック
     2. 「実行」ボタンをクリック
   - インストール先を選択（デフォルト: `C:\Program Files\Nightreign Timer`）
   - デスクトップショートカットを作成するか選択

3. **起動**
   - デスクトップのショートカットをダブルクリック
   - またはスタートメニューから「Nightreign Timer」を検索

#### 方法2: ポータブル版（インストール不要）

1. **ポータブル版をダウンロード**
   - [Releases](https://github.com/kazumayokota/Nightreign-Timer/releases)ページを開く
   - 最新バージョンの `Nightreign Timer-Portable-1.0.1.exe` をダウンロード

2. **任意の場所に配置**
   - USBメモリや任意のフォルダに配置可能
   - ダブルクリックで直接起動

3. **注意事項**
   - 設定ファイルは実行ファイルと同じ場所に保存されます
   - レジストリへの書き込みは行われません

### アンインストール

#### インストーラー版
1. Windowsの設定を開く
2. 「アプリ」→「インストールされているアプリ」
3. 「Nightreign Timer」を選択
4. 「アンインストール」をクリック

#### ポータブル版
実行ファイルを削除するだけでOKです。

## 🚀 使い方

### 基本操作

#### 1. タイマーの開始・停止
- **キーボード**: `Ctrl+S` でタイマーを開始/一時停止
- **右クリックメニュー**: オーバーレイを右クリック→「リセット」

#### 2. フェーズ指定で開始
タイマーを特定のフェーズから開始できます：

- `Ctrl+1`: 午前フェーズ（0:00）から開始
- `Ctrl+2`: 午前収縮（4:30）から開始
- `Ctrl+3`: 午後フェーズ（7:30）から開始
- `Ctrl+4`: 午後収縮（11:00）から開始

**または** システムトレイのアイコンを右クリック→「フェーズから開始」

### 設定画面

#### 設定画面を開く
- オーバーレイの右上の⚙️アイコンをクリック
- または右クリックメニュー→「背景画像を設定」
- またはシステムトレイアイコンを右クリック→「背景画像を設定」

### カスタマイズ

#### 背景画像の設定
1. 設定画面を開く
2. 「背景画像」セクションで「画像を選択」をクリック
3. 画像ファイル（JPG, PNG, GIF, BMP, WebP）を選択
4. スライダーで以下を調整：
   - **拡大率**: 10% ～ 500%
   - **X位置**: 水平方向のオフセット（-2000px ～ 2000px）
   - **Y位置**: 垂直方向のオフセット（-2000px ～ 2000px）
   - **不透明度**: 背景画像の透明度（0% ～ 100%）
5. プレビューでリアルタイムに確認
6. 「保存して適用」をクリック

#### フォント・色のカスタマイズ
1. 設定画面の「外観設定」セクション
2. 以下を変更可能：
   - **カスタムフォント**: TTF/OTFフォントファイルをアップロード
   - **時刻の色**: メインの時刻表示の色
   - **ステータスの色**: ステータステキストの色
   - **バッジ背景色**: 「収縮中」バッジの背景色
   - **バッジ文字色**: 「収縮中」バッジの文字色
   - **オーバーレイ背景**: オーバーレイ全体の背景色と不透明度

#### キーボードショートカットのカスタマイズ
1. 設定画面の「キーボードショートカット」セクション
2. 各ショートカットの入力欄をクリック
3. 新しいキーの組み合わせを入力（例: `Ctrl+Shift+T`）
4. 「保存して適用」をクリック

**デフォルトのショートカット:**
- 開始/停止: `Ctrl+S`
- 午前フェーズ: `Ctrl+1`
- 午前収縮: `Ctrl+2`
- 午後フェーズ: `Ctrl+3`
- 午後収縮: `Ctrl+4`

### VOICEVOX設定

#### 自動起動の設定
1. 設定画面の「VOICEVOX設定」セクション
2. 「VOICEVOX実行ファイルを選択」をクリック
3. `VOICEVOX.exe` を選択（通常は `C:\Program Files\VOICEVOX\VOICEVOX.exe`）
4. 「保存して適用」をクリック
5. 次回起動時から自動的にVOICEVOXが起動します

#### 音声設定
- **キャラクター選択**: ドロップダウンから好みのキャラクターを選択
- **音量調整**: 0% ～ 100% でボリューム調整
- **音声テスト**: 「音声テスト」ボタンで確認

#### 音声通知のタイミング
以下のタイミングで自動的に音声通知が流れます：

| 時刻 | メッセージ |
|------|-----------|
| 4:20 | 収縮10秒前です。 |
| 4:25 | 収縮5秒前です。 |
| 4:30 | 午前の収縮が開始されます。安全エリア内に退避してください。 |
| 7:30 | 午後が始まります。 |
| 10:50 | 収縮10秒前です。 |
| 10:55 | 収縮5秒前です。 |
| 11:00 | 間も無く最後の収縮が始まります。 |
| 11:05, 12:00, 13:00 | 退避してください。 |

### その他の機能

#### クリック透過モード
マウス操作がオーバーレイを通過してゲームに届くようになります。

- システムトレイアイコンを右クリック→「クリック透過をON」
- 無効にする場合は「クリック透過をOFF」

#### 最前面に移動
他のウィンドウに隠れた場合、手動で最前面に戻せます。

- システムトレイアイコンを右クリック→「最前面に移動」

## 🛠️ トラブルシューティング

### VOICEVOXに接続できない
1. VOICEVOXが起動しているか確認
2. 設定画面で「接続確認」の結果を確認
3. VOICEVOXのポート設定を確認（デフォルト: 50021）
4. ファイアウォールでブロックされていないか確認

### オーバーレイが表示されない
1. システムトレイにアイコンがあるか確認
2. システムトレイアイコンを右クリック→「最前面に移動」
3. タスクマネージャーでプロセスが動いているか確認

### 背景画像が表示されない
1. 画像ファイルのパスが有効か確認
2. 対応形式（JPG, PNG, GIF, BMP, WebP）か確認
3. ファイルが破損していないか確認
4. 設定画面で画像を再選択

### 音声が再生されない
1. VOICEVOXが正常に起動しているか確認
2. 設定画面で音声テストを実行
3. システムの音量設定を確認
4. 他のアプリで音声が再生できるか確認

### ショートカットキーが動作しない
1. 他のアプリと競合していないか確認
2. 設定画面でショートカットキーを変更してみる
3. アプリを再起動

### 設定が保存されない
1. アプリを管理者権限で実行してみる
2. `%APPDATA%\overlay-timer` フォルダの権限を確認
3. ディスク容量が十分か確認

### 設定ファイルが破損した
アプリは自動的にバックアップから復元を試みます。手動で復元する場合：

1. アプリを終了
2. `%APPDATA%\overlay-timer` を開く
3. `background-settings.json.backup` を `background-settings.json` にリネーム
4. アプリを再起動

## 🔒 セキュリティに関する注意事項

### VOICEVOX実行ファイルの選択
- **必ず公式版のVOICEVOXを使用してください**
- 不明な実行ファイルを指定しないでください
- ファイル名に「voicevox」を含まないファイルは起動できません

### 設定ファイルの編集
- 設定ファイルを手動で編集しないでください
- 破損した場合、自動的にバックアップから復元されます

### ファイルの取り扱い
- 信頼できないソースからの画像・フォントファイルは使用しないでください
- アプリは選択されたファイルの拡張子を検証します

### 技術スタック
- **Electron** v31.0.0 - デスクトップアプリケーションフレームワーク
- **Node.js** - ランタイム環境
- **axios** - HTTP通信（VOICEVOX API）
- **VOICEVOX API** - 音声合成

### アーキテクチャ
- `main.js` - メインプロセス（ウィンドウ管理、IPC、VOICEVOX制御）
- `renderer.js` - レンダラープロセス（タイマーロジック、UI更新）
- `settings.js` - 設定画面のロジック
- `preload.js` - セキュアなIPC通信ブリッジ
- `validator.js` - 入力値の検証とサニタイゼーション

### セキュリティ設定
- `webSecurity: true` - XSS攻撃対策
- `contextIsolation: true` - プロセス間分離
- `nodeIntegration: false` - レンダラーでのNode.js無効化
- 入力値の厳格なバリデーション
- ファイル拡張子のホワイトリスト
